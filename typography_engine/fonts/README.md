# fonts/ -- open-licence typefaces the engines can draw with

All files here are from the Google Fonts repository (github.com/google/fonts, `ofl/`)
and are licensed under the SIL Open Font License 1.1, which permits bundling them in
this software and using them in the portraits it renders and sells. Each family's
licence text is in its `ofl/<family>/OFL.txt` in that repository.

Select one with `TYPO_FONT=<file name>` (and `TYPO_FONT_WEIGHT=<axis value>` for a
variable face, e.g. 700); unset keeps the box font, DejaVu Sans Bold. See
app/typeface.py. Fetched 2026-09-19 for the typeface trial (programme item 2).
